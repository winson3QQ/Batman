**Flutter contrast 的例外（逐畫板，73 個，`app/test/support/a11y.dart` 的 `a11yExceptions`）**：Flutter 的規則把畫面縮到 1× 再取「最常出現的深色」當文字色。13–16 dp 的中文筆畫在 1× 只有 1–2 像素寬，最常出現的深色是反鋸齒的灰階，不是字的顏色。例：「說明」頁內文用 ink #1A1915 畫在 #EFEAE0 上（15.6:1），Flutter 量成 #A39F98、2.20:1。例外**有條件**：(1) 被例外的畫板上，Flutter 判 FAIL 的每一個節點都必須在 contrast2x 量到而且通過，否則 FAIL（`excused, but "…" is not a passed contrast2x text`；上面 sub 的負向對照同時觸發了這一條）；(2) 例外的規則變成通過時，例外本身就 FAIL（負向對照：在 `home_all_fine_dark` 加一個例外 → `A11Y-FAIL home_all_fine_dark contrast: stale exception (the rule passes now)`）；(3) 只有 contrast 可以被例外。拿掉一個例外（`help_light`）→ `A11Y-FAIL help_light contrast: SemanticsNode#5(…)`。
**這份例外清單是 Windows 光柵化的結果**：同一個字型檔在 WSL（Linux，經 `/mnt/c/Windows/Fonts/NotoSansTC-VF.ttf`）上畫，Flutter 的規則 73 個全過（第一次在 WSL 跑出 146 行 `stale exception`），所以「例外已過期」只在 Windows 判；條件 (1) 在兩邊都判。WSL 上 contrast2x 也全過（`+371: All tests passed!`）。
**沒有中文字型的機器**（例如 GitHub Actions 的 ubuntu，`loadFonts` 找不到任何一個字型檔、用 flutter_test 的方塊字）：兩條對比規則不跑，每個畫板印 `A11Y-SKIP <畫板> contrast, contrast2x: … NOT judged in this run`（tap48 與實心照跑）。這種環境**沒有判對比**，不算通過；對比只在 Windows 與 WSL（有這個字型檔）判。
**兩條對比規則都看不到的**：Flutter 只量「標籤剛好等於一個 Text」的語意節點（BatRow 合併的標題＋副標被跳過，不是通過），也跳過停用的節點；contrast2x 跳過圖示字型、停用按鈕裡的字、不完整在畫面裡的字、中心被蓋住的字。表情符號（6.x 全隊）在測試裡沒有字型。真機的數字由 §4 的真機場次用同一個 `measure()` 量（`app/tool/device_contrast.dart`，本 PR 只寫了工具與測試，沒有在手機上跑）。

## 渲染限制（判讀時要扣掉的）

- 每張只到第一個畫面（915 dp）；`long_home_problem` 的「可以做的事」被切在底部。
- 畫板是 `home:` 直接開的，多數頁沒有返回鍵（實機從上一頁進來會有）；4.x 是 push 進來的，有返回鍵。
- `1.1_startup_splash_light` 沒有臂章圖、`_dark` 有：圖片資源是非同步載入，淺色那張是那個檔案的第一個畫板、圖還沒載完。

- 6.x 全隊的 🟢 ⚪ ❔ 在測試字型裡是方框（`team_fresh`），實機是表情符號。
- 假資料造成的：8.1 / 8.4「版本讀不到」、關於頁「app 版本」沒有值、國家 / 手機 Wi-Fi 的「另一個操作還在進行：建立網路」（session 被佔用）、`pick_network` 停在「正在讀取網路紀錄」、`settings_dev` 三個開發項目是灰的「沒有啟動時的金鑰檢查結果」（畫板沒有給金鑰結果）、3.4「1 秒內沒找到」（測試的搜尋窗是 800 ms，實機 60 s）。
- `3.4_refused` 的錯誤句是照 bridge `ClaimStep::ended`（`app/rust/bridge/src/api/claim.rs:186-193`）的格式寫的假回覆（`節點拒絕開始認領` + 技術段 `BeginRefused：Busy`），不是從節點收到的。
- 摺疊的「技術資訊」除了 2.4_tech_opened、5.5 以外都沒打開；摺疊裡的字沒看。
- 仍然沒有渲染的：5.8 改國家的確認框、9.1 選檔、9.x 傳送中（有進度的上傳）、3.7 恢復成功 / 失敗的結果、10.7 授權頁（LicensePage）、7.2（設計不做）。舊控制台 `NodesPage` 已經刪掉（`grep -rn "class NodesPage" app/lib` = 0 行），沒有畫板可看。
